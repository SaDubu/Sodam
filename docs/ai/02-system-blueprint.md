# Sodam 시스템 설계도

> 상태: 설계 검토용. 이 문서는 `01-architecture.md`의 요구사항을 시각적으로 정리한 보조 설계도이며 구현 승인 전에는 코드로 전환하지 않는다.

## 1. 시스템 경계

```text
사용자 PC (로컬 전용)
┌─────────────────────────────────────────────────────────────────┐
│ 데스크톱 UI                                                       │
│  URL 입력 · 파일 선택 · 진행 상태 · 검수 큐 · 전사문 · 2문장 요약 │
└──────────────────────────────┬──────────────────────────────────┘
                               │ 작업 요청 / 취소 / 결과 조회
┌──────────────────────────────▼──────────────────────────────────┐
│ 작업 관리자                                                       │
│  작업 상태 전이 · 전용 임시 경로 생성 · 보관 정책 적용            │
└───────┬──────────────────────┬─────────────────────────┬────────┘
        │                      │                         │
        │ URL 입력             │ 로컬 영상/음성          │ SQLite + JSON
        ▼                      ▼                         ▼
┌──────────────┐      ┌──────────────────┐       ┌─────────────────┐
│ 소스 어댑터  │      │ 미디어 어댑터    │       │ 작업 저장소     │
│ URL 검증     │      │ 입력 검증        │       │ 메타데이터      │
│ 일시 음성획득│      │ 오디오 표준화    │       │ 전사/변경 이력  │
└──────┬───────┘      └────────┬─────────┘       │ 요약/검수 큐    │
       └──────────────┬────────┘                 └─────────────────┘
                      ▼
             ┌────────────────┐
             │ 로컬 STT 엔진  │
             │ 시간 구간 원문 │
             └───────┬────────┘
                     ▼
┌─────────────────────────────────────────────────────────────────┐
│ 텍스트 파이프라인                                                 │
│ 보호 토큰 → 안전 규칙 정리 → 청크 문맥 교정 → 차이 검증/복원     │
└───────────┬───────────────────────────────────────┬─────────────┘
            │                                       │
            ▼                                       ▼
 ┌────────────────────┐                 ┌────────────────────────┐
 │ 최종 전사문         │                 │ 검수 큐                 │
 │ 구간/시간/변경 이력 │                 │ 위험 변경만 사용자 확인 │
 └──────────┬─────────┘                 └────────────────────────┘
            ▼
 ┌────────────────────────────────────────────────────────────────┐
 │ 계층형 로컬 요약: 구간 요약 → 통합 → 최대 두 문장 + 근거 구간 ID │
 └────────────────────────────────────────────────────────────────┘
```

외부 네트워크가 허용되는 유일한 경계는 사용자가 권한을 가진 URL의 일회성 음성 획득과, 사용자가 시작한 모델 설치다. 전사·교정·요약은 모두 로컬에서 수행한다.

## 2. 작업 상태 전이

```text
queued
  └─> acquiring ─> extracting ─> transcribing ─> normalizing
                                                └─> correcting
                                                     └─> reviewing
                                                          └─> summarizing
                                                               └─> completed

각 실행 상태 ───────────────────────────────> cancelling ─> cancelled
각 실행 상태 ───────────────────────────────> failed
completed / cancelled / failed ─────────────> cleaning ─> archived
```

- 취소 요청은 현재 단계가 안전하게 중단된 뒤 `cancelled`로 끝난다.
- 성공, 실패, 취소 모두 `cleaning`을 거친다.
- 정리 대상은 해당 작업의 전용 임시 디렉터리로 제한한다. 이 밖의 경로는 삭제하지 않는다.

## 3. 산출물과 보존 경계

| 구분 | 대표 산출물 | 기본 보존 | 저장 위치 |
|---|---|---:|---|
| 임시 입력 | URL에서 받은 미디어, 추출 오디오 | 아니오 | 작업별 `tmp` |
| STT 원문 | `raw_segments.json` | 정책 선택 | 작업 결과 |
| 교정 결과 | 최종 구간, 변경 이력, 검수 큐 | 예 | 작업 결과 |
| 요약 | 두 문장 요약, 근거 구간 ID | 예 | 작업 결과 |
| 모델 | Qwen/Whisper 가중치와 캐시 | 예, Git 제외 | `MODEL_HOME` (저장소 밖) |

모델, 사용자 미디어, 전사문, 요약, 로그, 인증 정보는 Git 추적 대상이 아니다. 사용자 데이터는 Git 작업 트리 밖의 데이터 디렉터리에 둔다.

## 4. 텍스트 처리 불변식

```text
STT 원문(시간 구간 유지)
  → 숫자·날짜·금액·URL·약어·고유명사 보호 토큰화
  → 공백/명백한 문장부호만 규칙으로 정리
  → 인접 구간 단위의 JSON 문맥 교정
  → 보호 토큰 복원 및 원문 대비 차이 검증
  → 안전 변경은 반영, 위험 변경은 검수 큐로 이동
```

- 모든 최종 구간은 원본 `segment_id`, 시작/종료 시간, 원문을 계속 참조할 수 있어야 한다.
- 보호 토큰은 100% 동일하게 복원되어야 한다.
- 숫자·고유명사·사실관계의 변경은 자동 확정하지 않는다.
- 요약은 최종 전사문에 없는 사실을 추가하지 않으며 문장마다 근거 구간 ID를 보관한다.

## 5. 실행 리소스 원칙

```text
STT 모델 로드/실행 → 메모리 해제 또는 유휴화 → Qwen 모델 로드/실행
```

두 대형 모델을 동시에 VRAM에 유지하지 않는다. Qwen 교정은 전체 영상이 아닌 인접한 짧은 청크를 처리하고, 요약은 청크별 결과를 계층적으로 통합한다.

## 6. 승인 이후의 경계

`APPROVE DESIGN` 이전에는 이 설계도와 기존 설계 문서만 변경 가능하다. 정확히 승인된 뒤에도 첫 단계는 구현이 아니라 코드·테스트 도구의 **골격** 및 `docs/ai/04-implementation-order.md` 작성이다. 실제 함수 로직, 실제 테스트 로직, 외부 호출, 삭제, 커밋·푸시는 별도 명시 승인이 필요하다.

## 7. 검토 체크리스트

- [ ] 최소 지원 PC의 RAM/VRAM 및 Q4/Q5 기본 프로필을 정한다.
- [ ] 지원할 URL 소스와 사용자 권한 확인 방식을 정한다.
- [ ] 기본 보관 기간과 결과 암호화 필요 여부를 정한다.
- [ ] 사용자/채널 용어집의 제공 범위를 정한다.
- [ ] 요약을 두 문장만 제공할지, 챕터별 요약도 제공할지 정한다.
- [ ] 상용 배포 여부와 모델·도구 라이선스 검토 범위를 정한다.

세부 함수 계약, 테스트 계약, 파일별 책임은 `01-architecture.md`를 정본으로 한다.
