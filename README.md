# Sodam

로컬 영상 전사·교정·최대 두 문장 요약 도구의 승인된 **골격**입니다.

현재는 인터페이스, 테스트 자리표시자, 구현 순서만 존재합니다. 모델 설치, URL 획득, 미디어 변환, STT, LLM 호출, 데이터 저장·삭제, 실제 테스트는 구현되지 않았습니다.

세부 설계는 `docs/ai/01-architecture.md`, 작업 순서는 `docs/ai/04-implementation-order.md`를 확인합니다. 실제 구현은 작업 하나씩 `Statement_of_Functions.md`에 명세하고 별도 승인받아 진행합니다.
